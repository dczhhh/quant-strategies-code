# 个股横截面动量 V1：研究设计与实现

日期：2026-10-22。状态：独立研究模块，未合并，不改变 ETF 策略或生产默认。
本版交付选股、目标权重、现金账户执行适配、合成场景和回归测试；没有真实历史收益结论。

## 为什么选择这个基线

首版研究“过去中期表现相对较强的股票是否继续较强”，只持有多头。
使用一个收益因子，避免把多个高度相关技术指标叠加后再挑历史表现最好的组合。

| 候选 | 优点 | 主要代价 | 本版处理 |
| --- | --- | --- | --- |
| 12-1 动量 | 规则少、可解释、有成熟研究参照 | 反应较慢；风格反转时可能落后 | 默认基线 |
| 6-1 动量 | 更快识别新领导股 | 换手、噪声和调参空间增加 | 参数支持，先不根据结果挑优 |
| 收益/波动率 | 可抑制高波动股票占优 | 同时混入低波动效应 | 暂不加入 |
| 行业内动量 | 缓解行业集中 | 改变研究问题，增加分组边界 | 先采用行业持仓上限 |

Kenneth French 的月度动量组合按 prior (2–12) return 分组，排除最近一个月。
本版用 252 与 21 个交易日近似，不宣称精确复现月历定义或论文组合。
French 动量因子包含多空组合，本项目仅持有赢家，因此不能照搬因子历史收益。

Daniel/Moskowitz 研究指出，动量崩溃与此前市场下跌、高波动及随后反弹有关。
其多空组合中输家空头的反弹风险尤其重要；不能直接把论文跌幅套到本纯多头组合。
本项目仍须检验 V 型反转、集中持股和错过反弹的风险。

## 冻结的首版规则

1. 默认为美国注册、美国主要交易所上市的普通股，美元计价；排除 ADR、加拿大股票、ETF、
   小盘及明确排除的 GME/AMC/KOSS。默认历史市值至少 100 亿美元。
   中盘研究可降低市值阈值，但至少 20 亿美元且每只提供研究理由；这不改变数据采集授权校验。
2. 历史时点的最近 20 个交易日平均原始成交金额至少 2000 万美元，原始股价至少 5 美元。
   阈值是研究设计参数，不是文献证明的最优值。元数据不能使用今天的市值、行业或上市状态替代。
3. 至少 253 个连续交易日端点。信号为 `TR[t-21] / TR[t-252] - 1`，仅选正动量。
   TR 为包含拆股和股息的总回报指数；不能把复权价格用于真实下单或重复计入账户分红。
4. 按动量降序、代码升序处理并列，最多选 5 只。默认每只名义 19%；执行前留出总资产
   0.2% 的费用余量，所以提交目标为每只 18.96%，最多 94.8%。剩余现金含费用缓冲。
   实际仓位会受取整、成交价和订单拒绝影响；不能保证始终达到 95%。
5. 单只目标 10%–25%，行业总权重不超过 40%。默认同一行业最多两只。
   不足 5 只时不强行放大剩余持仓，空缺留现金。此规则用于降低集中度，不用于预测收益。
6. 默认月末收盘信号，下一月第一个交易日启动；可配置半月（每月首个交易日和16日或其后首个交易日）。
   半月不是每隔15自然日，也不是每隔15交易日。
7. 正常调仓只在纽约时间开盘后30至120分钟内进行，即通常10:00–11:30。
   使用细于或等于30分钟的原始执行行情；`NEXT_BAR`、先卖后买，最多延续5个交易日。
   缺少上一交易日完整快照时停止新计划并取消未完成旧计划。
8. 普通调仓增减量朝零方向取到0.1股；全额退出保留公司行动产生的残余股数，避免留下碎股。
   核心风控强制减仓也保留其计算精度。所有账户现金与持仓均由原有 broker 管理。
9. 财报禁入、财报前退出、公告可知时间、盘前盘后禁入、T+1/T+2历史结算、现金预留、
   非零阶梯佣金和滑点由现有约束层执行。财报导致空缺时，本期不按成交结果重新选第六名。
   强制财报退出不受晨间调仓窗口限制，仍须在合法常规交易时段执行。
10. 可选 SPY 风控：连续两个完整收盘的总回报指数低于各自200日均线，下一次合法窗口退出；
    恢复后只在计划调仓日买回。默认关闭，以保留纯选股基线。
    这只是待检验的二元风控，不声称等同于现有 ETF 多档降仓信号，也不声称解决 V 型反转。

## 接口与可运行入口

配置：`config/stock_momentum_v1.json`。
模块：`ml4t.backtest.strategies.stock_momentum`。

```bash
uv sync --dev --locked
uv run python examples/stock_momentum_demo.py
uv run pytest tests/strategies/test_stock_momentum.py tests/constraints --no-cov -q
```

`StockObservation` 是某一历史交易日已知的证券身份、上市日期、行业、市值、原始价格、平均成交金额与总回报序列。
`MomentumSnapshot.sessions` 给出全部价格对齐的连续交易日，`available_at` 必须不早于该日收盘。
`SnapshotSource` 仅返回当前时刻已发布的快照；同一历史 session 不允许被事后修订覆盖。
`select_stocks` 输出目标权重、分数和排除理由，供研究运行器使用。
`stock_momentum_engine` 接收原始分钟 DataFeed、策略、执行上下文和 EarningsProvider。
独立策略可以通过公开 Engine 运行，但不能绕过约束 broker。

缺失策略：默认 `abort`；显式 `skip` 只跳过缺失元数据/价格的个股。
只有显式 `listed_on` 证明上市时间不足时才正常排除；老股票历史长度不足按缺失价格处理。
未来元数据、重复证券ID、非连续交易日一律拒绝。
SPY数据缺失时不能假定牛市或触发清仓。信号弱/不可投和数据未知是不同状态。

## 真实数据与验收边界

本次从公开主分支建立独立 PR。ETF 研究、分红证据和用户已认可的小数股手续费修订仍在不同研究分支，
没有把那些未合并分支的内容悄悄纳入本 PR。V1 引擎入口仅运行明确标记的合成输入；
`retrospective_research` 快照可用于独立选股检查，但不允许冒充合成数据进入该入口。
此限制是版本能力边界，不要求用户重新批准已授权的 API 使用。

真实回测接入前需要绑定以下事实：

- 每次调仓的历史股票池及退市证券、证券稳定ID和代码变更，不可用今天的成分股倒推历史。
- 当时可知的市值、行业、20日成交金额和财报日历版本；`available_at` 字段本身不是证据。
- 总回报序列与原始执行价格、拆股、现金分红的对应关系，以及普通美股分红10%税率。
- 用户已认可的手续费运行版本，以及其现存财报、Bracket、结算、分红拆股回归。
- 涵盖预热期的原始行情。2022年首个调仓信号还需2021年及更早端点，不能补零或跳过预热。

本模块不建立新的分红或现金账本、不访问券商下单、不联网下载股票池，也不发布真实绩效。
快照中的 `synthetic`/`retrospective_research` 是输入标签，不会自动授予 PIT_verified 或绩效验收资格。
