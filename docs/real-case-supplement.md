# Window-covered reverse-split and reorganization inputs

The GE August 2021 event is outside the current Starter five-year bar window.
It remains unverified; its old responses and reservations are preserved. This
separate operator captures thirteen fixed products in new
`real-case-supplement-v1-*` namespaces, never changing prior plans or budgets.

SQQQ's November 7, 2024 1:5 ordinary reverse split is documented in ProShares'
October 28 announcement and its Form 8937. Raw and split-only adjusted daily bars
are obtained separately; split metadata extends to the current review date so
later share-basis changes are not silently excluded. Cash redemption of fractional
shares is not inferred or supported by this capture. SQQQ is an event-validation
sample, not an instrument added to the A2 strategy.

WOLF is explicitly named by the owner as an event candidate. Its September 29,
2025 SEC filing documents cancellation of old shares, replacement stock and
conditional further stock, not an ordinary value-preserving reverse split. Its
January 2026 issuer release documents a later restructuring milestone. The
supplement includes separate pre/post identity requests, nearby raw/adjusted bars,
split metadata and the two public documents. A vendor split label or the same
ticker cannot prove unchanged security identity or convert it into a supported
split. No WOLF return, valuation or ordinary split acceptance is computed.

Acquisition is owner-dispatched, reviewed-SHA pinned and main-only in the existing
protected archive environment. Each product gets one create-only reservation
before one request. Unknown outcomes remain reserved; no retries, redirects,
pagination or arbitrary URLs are permitted. All bytes stay on GitHub runners and
the private data repo; no public data artifact, exception body or private account
image is emitted. Same-runner and fresh-runner readback have no provider key and
use a read-only GitHub client. Existing credentials and branch restrictions do
not expand. Invented transport fixtures are not real economic cases.

All certification remains `UNVERIFIED` and all raw/PIT/archive/engine/admission
flags remain false. Official bytes, even when fetched successfully now, are not
automatically historical knowledge evidence. Full account/order/risk/NAV event
replay, ETF classification and actual fractional-cash evidence remain separate
acceptance requirements. Strategy PR #6 remains blocked and unmerged.
