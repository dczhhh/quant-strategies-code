# Retained annual workbook copies

This read-only adapter opens exactly private candidate intake commit
`ca9d5c3532877b263e0c2bc73c6931fe0bc8312b`. It issues no new source requests,
resets no earlier reservation, writes no archive and invokes no Engine.

The 2023 and 2024 ICI Primary workbooks are third-party archival copies found
through public tax-document collections, not downloads from the issuer origin.
The retained hashes establish byte identity only. Original issuer authenticity,
transport request clocks, finality, investor tax treatment and historical PIT
remain unverified. Local file-completion observations are not historical known-at
times. These limitations must accompany any later retrospective inputs/results.

The adapter preserves each vintage's actual title, header text and row offset.
It requires unique ticker/ex-date events, matching CUSIP, record/pay dates and
original-share cash against retained issuer distribution history within the
existing USD 1E-8 tolerance. All 15 numeric fields must be present. Ordinary,
qualified and current-year components must reconcile; nonordinary components
must be explicit zero. Estimated or extended rows are rejected. Four events per
asset per year are required: 96 event checks across the fixed twelve assets.
No 2022 ordinary-dividend assumption is silently extended to another year.

The retained complete SEC filing corroborates fiscal-year summaries only; it is
not substituted for calendar-year per-event components. The original candidate
manifest remains marked unverified. A later continuous builder must additionally
match native vendor cash, validate every underlying source, and retain this
third-party provenance. This module alone grants no continuous-input, Engine,
PIT or performance admission.
