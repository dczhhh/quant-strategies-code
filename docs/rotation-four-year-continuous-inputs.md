# One continuous raw-backed input bundle

This opt-in research builder is not an Engine runner. Existing strategy defaults,
old studies and reservations are unchanged. No new market or official-source
request is permitted. The hosted archive entry point also rejects a market key.

Before combination, all three prior input builders reopen their original raw
archives and run their original byte/source/calendar/issuer checks. Rebuilt
normalized bytes must exactly match the accepted quantity-exit input pins.
Reading those old normalized files alone is not sufficient. All 2,304 new raw
products must pass frozen-source read-only capture verification. Full-span raw
split sources are additionally reopened at their fixed original commit pins.

Old source IDs are deterministically namespaced by window. Overlapping daily
closes, OHLCV minute bars, native dividend identities/cash/dates, split ratios and
security identities must agree exactly as Decimals. Fixed window priority only
selects provenance for identical observations; it never repairs conflicts.
All warmup closes from 2020-11-02 are preserved. There must be 1,003 continuous
execution sessions, 13 completed minute points per asset/session and twelve
assets, from 2022-01-03 through 2025-12-31. No annual reset or return splicing.

Native cash, CUSIP and ex/record/pay fields for all 192 execution dividends must
match retained issuer history within the original USD 1E-8 tolerance. The owner
assumption applies only to 2022. For 2023/2024, actual same-year fields in the
retained third-party archival workbook copies replace the old short-window
2024 assumption. Their issuer-origin hash authenticity, finality and historical
PIT remain unverified; provenance limitations are retained in every audit.
2025 uses the original retained issuer workbook's existing strict field checks.
All 15 numeric fields remain explicit. No missing field becomes zero.

The raw source must contain the actual five 2-for-1 split events on 2025-12-05,
with native event identity, for XLB/XLE/XLK/XLU/XLY. The independently transcribed
settlement reference is checked against both production collaborators for all
1,003 trade dates, including the trade-date T+2 to T+1 transition. Year-end SPY
dividend payment in January 2026 is preserved as its actual payable date, not
advanced into December cash. Exercising actual Engine positions/orders/ledgers
across those boundaries is a subsequent required stage, not established here.

The archive operator shares only immutable Git objects, never ref or privacy
responses, among read-only clients. Logical inputs and full audit bytes are
bounded, gzip mtime-zero, SHA256/Git bound, create-only, and privately retained.
A separate fresh hashseed-33 job must rebuild all raw-backed bytes and compare
every file without archive writes or provider keys. No Engine, actual broker,
issuer-authenticity, historical PIT or performance admission is claimed.

Before installing any workflow-only launcher: complete source CI, all twelve
Ecosystem lanes and specialized checks must succeed on the exact immutable
source; original frozen capture must also succeed. Keep source Draft/unmerged.
